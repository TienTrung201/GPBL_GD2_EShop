------------------------------------------- Cách auto vào server không cần mật khẩu-------------------------------
🔐 Hướng dẫn thiết lập SSH Key để đăng nhập không cần mật khẩu
Việc thiết lập SSH Key giúp bạn đăng nhập vào server mà không cần nhập mật khẩu mỗi lần.

✅ 1️⃣ Kiểm tra xem bạn đã có SSH Key hay chưa
Mở terminal (hoặc Command Prompt trên Windows) và chạy:

ls ~/.ssh
📌 Nếu thấy file id_rsa và id_rsa.pub, nghĩa là bạn đã có SSH Key.
📌 Nếu không có file nào, hoặc muốn tạo mới, làm bước tiếp theo.

✅ 2️⃣ Tạo SSH Key mới
Chạy lệnh sau để tạo SSH Key (bỏ qua nếu đã có):


ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
📌 Giải thích:

-t rsa: Tạo key theo chuẩn RSA.
-b 4096: Độ dài key 4096-bit (bảo mật cao).
-C "your_email@example.com": Gán email vào key để nhận diện.
🔹 Khi được hỏi "Enter file in which to save the key", nhấn Enter để lưu vào mặc định (~/.ssh/id_rsa).
🔹 Khi được hỏi "Enter passphrase (empty for no passphrase)", bạn có thể để trống (hoặc đặt mật khẩu nếu muốn bảo mật hơn).

📌 Sau khi tạo xong, bạn sẽ có 2 file:

~/.ssh/id_rsa → Private Key (bí mật, không chia sẻ)
~/.ssh/id_rsa.pub → Public Key (dùng để đưa lên server)
✅ 3️⃣ Copy SSH Public Key lên server
Chạy lệnh sau để copy SSH Key vào server (thay IP của bạn vào):


ssh-copy-id -i ~/.ssh/id_rsa.pub root@103.163.118.217
📌 Nếu ssh-copy-id không có trên máy của bạn, làm thủ công:

Mở file Public Key trên máy:

cat ~/.ssh/id_rsa.pub
Copy toàn bộ nội dung (nó sẽ bắt đầu bằng ssh-rsa ...).
SSH vào server:

ssh root@103.163.118.217
Dán key vào file ~/.ssh/authorized_keys:

echo "NỘI_DUNG_KEY_BẠN_VỪA_COPY" >> ~/.ssh/authorized_keys
Đảm bảo quyền đúng cho file:

chmod 600 ~/.ssh/authorized_keys
✅ 4️⃣ Kiểm tra đăng nhập bằng SSH Key
Bây giờ, thử đăng nhập vào server mà không cần nhập mật khẩu:


ssh root@103.163.118.217
✔ Nếu vào được mà không hỏi mật khẩu → Thành công! 🎉

✅ 5️⃣ (Tùy chọn) Tắt đăng nhập bằng mật khẩu (bảo mật hơn)
Nếu bạn chỉ muốn dùng SSH Key, có thể vô hiệu hóa đăng nhập bằng mật khẩu để tăng bảo mật:

Mở file cấu hình SSH:

sudo nano /etc/ssh/sshd_config
Tìm dòng:

PasswordAuthentication yes
và sửa thành:

PasswordAuthentication no
Lưu lại (Ctrl + X, Y, Enter).
Restart SSH để áp dụng thay đổi:

sudo systemctl restart ssh
📌 Lưu ý: Trước khi tắt đăng nhập bằng mật khẩu, hãy đảm bảo bạn có thể SSH vào bằng key!

🚀 Tóm lại:
✔ Tạo SSH Key: ssh-keygen -t rsa -b 4096 -C "your_email@example.com"
✔ Copy Key lên server: ssh-copy-id -i ~/.ssh/id_rsa.pub root@103.163.118.217
✔ Đăng nhập bằng SSH Key: ssh root@103.163.118.217
✔ (Tùy chọn) Tắt đăng nhập bằng mật khẩu để tăng bảo mật.

💡 Bạn làm thử đi, nếu có lỗi gì báo mình nhé! 🚀
